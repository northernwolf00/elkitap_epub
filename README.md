
# App Helper

**App Helper** is a Flutter package that allows users to open and read  files with ease. It provides powerful features such as opening  files from ***assets*** or ***local paths***, changing themes, adjusting font styles and sizes, accessing chapter contents, and more.

The reader is fully **responsive**, making it suitable for both smartphones and tablets of all sizes.

---

## Features

* **RTL (Right-to-Left) language support** for Arabic, Persian, Hebrew, Urdu, and other RTL languages
* **Automatic text direction detection** with proper alignment and navigation
* Change themes with 5 options: Grey, Purple, White, Black, and Pink
* Customize font style and size
* Access table of contents and navigate to specific chapters
* Display the current chapter name at the bottom of the screen
* Previous and next buttons to switch between chapters (RTL-aware)
* Adjust screen brightness
* Save book reading progress
* Smooth page flip animation while reading
* **Mixed content support** (LTR + RTL text in the same document)
* …and feel free to request new features or report issues internally

---
## RTL Language Support 🌍

**App Helper** includes first-class support for Right-to-Left (RTL) languages such as Arabic, Persian (Farsi), Hebrew, Urdu, and more.

### RTL Features

* **Automatic Detection** – Detects text direction directly from content
* **Smart Navigation** – Navigation controls adapt automatically for RTL reading
* **Correct Alignment** – Text alignment follows the detected direction
* **RTL-Friendly Table of Contents** – Proper indentation and layout
* **Mixed Content Handling** – Seamless LTR + RTL content rendering

### Supported Languages

* Arabic (العربية)
* Persian/Farsi (فارسی)
* Hebrew (עברית)
* Urdu (اردو)
* Pashto (پښتو)
* Sindhi (سنڌي)
* Kurdish (کوردی)
* Dhivehi/Maldivian (ދިވެހި)
* Yiddish (ייִדיש)

**App Helper** will automatically:

2. Apply correct RTL or LTR layout
